# Decisions

Where the brief was ambiguous, the simplest minimal option was chosen and recorded here.

| ID   | Decision                                                                                                                                                                                                                                        | Why                                                                                                                                       |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | New repo in `C:\Users\mattu\Desktop\personal-website` (clean tree on `feat/site-rewrite`); old folder untouched                                                                                                                                 | Outside OneDrive (no `.next` locks); only `main` had one README commit                                                                    |
| D-02 | Prisma **6.19** + `prisma.config.ts`, client in `node_modules` (not Prisma 7 driver adapters)                                                                                                                                                   | Proven with Next 16; fewer moving parts; upgrade later                                                                                    |

| D-11 | Detail pages are full pages; intercepting-route dialog skipped                                                                                                                                                                                  | Brief says optional; simplest path, better SEO                                                                                            |
| D-12 | Admin UI is English only, outside `/[locale]`; content edited per language                                                                                                                                                                      | Single owner                                                                                                                              |

| D-19 | Primary colour: blue (old site was blue)                                                                                                                                                                                                        | Brief                                                                                                                                     |
